# Actividad 4

## Descripción
Juego de cañon: se disparan proyectiles para reventar los balones azules antes de que crucen la ventana.

## Cómo se usa
- Da clic en la pantalla para disparar: el proyectil sale hacia donde diste clic.
- Hay que reventar los balones antes de que lleguen al otro lado.

## Cambios realizados
- Los balones que salen de la ventana se reposicionan y el juego nunca termina (Edgar).
